# كريم الناعوق — USDT Exchange MVP

واجهة عربية RTL فخمة لشراء وبيع USDT، تعمل محلياً على Windows عبر CMD، مع:
- أسعار بيع وشراء قابلة للتعديل من لوحة الإدارة.
- اسم ورقم وواتساب وتليجرام وعنوان محفظة قابل للتعديل.
- طلبات شراء وبيع.
- رفع صورة إثبات الحوالة.
- عنوان محفظة USDT TRC20 للمشتري.
- اختيار مزود الخدمة: جوال باي / بنك فلسطين / بال باي.
- إرسال تفاصيل الطلب إلى Telegram Bot.
- زر WhatsApp بإشعار جاهز للعميل.
- لوحة إدارة للطلبات وتغيير الحالة.

## التشغيل على Windows

1. ثبّت Python 3.11 أو أحدث.
2. افتح CMD داخل مجلد المشروع.
3. نفّذ:

```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

4. اضبط متغيرات البيئة في CMD:

```bat
set ADMIN_PASSWORD=ضع_كلمة_مرور_قوية_هنا
set SECRET_KEY=ضع_قيمة_عشوائية_طويلة_هنا
set TELEGRAM_BOT_TOKEN=توكن_البوت
set TELEGRAM_CHAT_ID=ايدي_المحادثة
```

5. شغّل:

```bat
python app.py
```

6. افتح:
http://127.0.0.1:5000

لوحة الإدارة:
http://127.0.0.1:5000/admin/login

كلمة المرور الافتراضية إذا لم تضبط ADMIN_PASSWORD هي:
123456
غيّرها فوراً.

## ملاحظات
هذا إصدار MVP للتجربة المحلية. قبل تشغيله على VPS بشكل عام، أضف HTTPS، حماية أقوى للـ admin، CSRF protection، rate limiting، إدارة أسرار آمنة، نسخ احتياطية، وسياسة خصوصية وشروط استخدام مناسبة لنشاطك.

لا تضع Bot Token أو كلمة مرور الإدارة داخل الكود أو ترفعها إلى GitHub.

- صفحة نتيجة الطلب تستخدم POST/Redirect/GET حتى لا يتكرر الطلب عند تحديث الصفحة.
- الرد `تم` على رسالة الطلب في Telegram يغيّر الحالة إلى `تم التحويل`.
